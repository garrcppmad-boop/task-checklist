# スプリント計画（短縮版・2週間）：チーム業務共有ボード

> 3スプリント版（[sprint-plan.md](./sprint-plan.md)）を **1週間 × 2スプリント（Week 22〜23）** に縮めた計画。
> 時間が足りないため、**Must の機能だけ** を作り、ローカルで動く状態を完成とする。

## 前提

| 項目 | 内容 |
|---|---|
| 期間 | Week 22〜23（2スプリント、各1週間） |
| 作業時間 | 週 42時間 × 2週 ＝ **84時間** |
| 範囲 | Must のみ。Should（F-10・F-12・F-16）と Could は対象外 |
| 3スプリント版から削ったもの | Should の機能（12h）／デプロイ（8h）／テストを権限・色分けに絞る（8h → 4h）／README を簡易版に（3h → 2h）／共通レイアウトを最低限に（5h → 3h） |
| スクラムイベント | 1スプリントあたり約3時間（流れは 3スプリント版と同じ） |

## スプリントの流れ（1週間）

```
Day 1  : スプリントプランニング（1時間）→ 開発作業
Day 2-5: 開発作業 ＋ デイリースクラム（毎日15分）
Day 6  : バッファ → スプリントレビュー（30分）→ レトロスペクティブ（30分・KPT）
```

## 遅れたとき・余ったとき

| 状況 | 対応 |
|---|---|
| 遅れた | 削る順：パスワードリセットのメール確認を後回し → 画像アップロード → キーワード検索（講師に相談） |
